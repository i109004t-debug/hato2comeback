# Postline

ファンクラブ等の、配信に同意した会員へメールを送るシステムです。このリポジトリには実装・インフラ定義・手順書があります。AWSへの構築、配送・復元の実機試験、本番受入は導入先で行います。

## はじめに読む文書

| 担当すること | 読む文書 |
|---|---|
| ログイン、宛先登録、配信・承認、結果の確認 | [利用者操作手順書](docs/利用者操作手順書.md) |
| AWSの契約、請求、アカウント、DNS、CLIの初期準備 | [AWS導入手順書](docs/AWS導入手順書.md) |
| Postlineの構築、SES本番申請、受入試験 | [構築手順書](docs/構築手順書.md) |
| 緊急停止、監視、再受入、バックアップと復元 | [運用手順書](docs/運用手順書.md) |
| 実装の仕様と判断 | [詳細設計書](docs/詳細設計書.md)、[基本設計書](docs/基本設計書.md)、[実装メモ](docs/実装メモ.md) |

通常の配信担当者はAWSへの登録やCLIの準備は不要です。管理者から渡された運営画面URLと個人のアカウントを使います。実際のURL・連絡先・配信上限は、導入担当者が利用者操作手順書の引継ぎ表に記入して配布します。

旧版の `docs/Postline_利用者向けご案内_v0.1.md` は設計時の資料として保存しています。日常操作には現行の利用者操作手順書を使ってください。

## 開発・検証

Node.js 24を使い、リポジトリ直下で実行します。外部パッケージのインストールは不要です。

```bash
node --test test/
```

シェルスクリプトの試験もあるため、bash 5以降と基本コマンドがPATHに必要です。WindowsではGit Bashから実行してください。AWSの構築にはAWS CLI v2も必要です。試験には偽物のAWSアダプターを使い、実際のAWSアカウントへ接続しません。

変更時は [AGENTS.md](AGENTS.md) を確認してください。デプロイ手順は変更セットの作成と実行を分けており、コマンド・アカウント・削除や置換をレビューしてから実行します。
